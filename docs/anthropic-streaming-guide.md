# Anthropic Claude Streaming & Tool Use Guide

このドキュメントでは、Anthropic SDK を使用したストリーミング処理およびツール実行（Tool Use）の仕組みについて解説します。

## 1. ストリーミングイベントの種類

`anthropic.messages.stream` で利用可能な主要イベントの役割とタイミングは以下の通りです。

| イベント名         | 発生タイミング         | 特徴                                                               | 主な用途                                                             |
| :----------------- | :--------------------- | :----------------------------------------------------------------- | :------------------------------------------------------------------- |
| **`text`**         | 文字生成のたび（逐次） | 新しく生成された文字列の断片（Delta）が届く。                      | **リアルタイム表示**。ユーザーに文字が打ち込まれている体感を与える。 |
| **`contentBlock`** | ブロックの完了時       | テキストや Tool Use といった「内容のカタマリ」が完成した時に発火。 | 特定のセクションが完了した後の後処理など。                           |
| **`message`**      | 全回答の完了時         | メッセージ全体（ID、Role、全Contentなど）が完成した時に発火。      | 回答全体の保存やログ出力。                                           |

## 2. `finalMessage` とツールの実行プロセス

ストリーミングを行っていても、ツールの実行指示（`tool_use`）はメッセージが完全に生成されるまで待つ必要があります。

### なぜ `finalMessage` を await するのか？

- ツールの実行には、AIが生成する「ツール名」と「引数（JSON形式）」が**1文字も欠けずに揃っている**必要があります。
- `await stream.finalMessage()` を呼ぶことで、すべてのストリーミングイベントが終了し、回答が完全に確定した状態を保証します。

### AIの回答フェーズ（ツール使用時）

1. **フェーズ1（思考と指示）**: AIが「在庫を調べよう」と判断。
   - ストリーミング（`text`）: 「在庫を確認しますね、少々お待ちください...」をリアルタイム表示。
   - バックグラウンド: ツール名と引数のJSONを生成。
   - **一旦停止**: ストリームが終了し、`finalMessage` に `tool_use` 指示が格納される。
2. **フェーズ2（現実の処理）**: プログラムが `finalMessage` から `tool_use` を検出し、実行。
   - 例: Shopify API を叩いて「在庫5」を取得。
3. **フェーズ3（最終回答）**: 取得結果をAIに返し、2回目のストリームを開始。
   - ストリーミング（`text`）: 「お待たせしました、在庫は5点です」と出力。

> [!NOTE]
> ツールを使わない一般的な会話の場合は、フェーズ1の終了時点でそのまま会話が完結します。

## 3. 設定値の目安 (`max_tokens`)

`max_tokens` は一回の生成で許容する最大トークン数です。

- **1,000トークンの目安**: 日本語で約1,000〜1,500文字程度。
- **プロジェクトのデフォルト (2000)**: A4用紙 2〜3枚分程度の出力が可能。一般的なチャット応答には十分な余裕があります。
- **調整の判断**: 回答が不自然に途切れる場合は、値を大きく（4096など）設定してください。
